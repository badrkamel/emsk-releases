# EMSK

A rooftop chase game for you and your friends. Jump, dash and take turns catching each other.

**[Download and play](https://emsk-play.vercel.app)** · [Player guide](https://emsk-play.vercel.app/help/) · [Release notes](https://emsk-play.vercel.app/updates/)

Windows and Linux desktop downloads include everything needed to play. Pick a guest name, create a room and share its six-character invite code. No signup or Godot installation required.

This is the public download and support repository. Game source is maintained separately.

## Early access

The public Frankfurt server supports two simultaneous rooms, with up to eight guests per room. Windows builds are currently unsigned. Check each release's SHA256SUMS.txt to verify downloads. Engine and font license notices are included in the archives.

Mobile, browser, ARM and macOS clients are not available in this release.

## Support

[Report a bug](https://github.com/badrkamel/emsk-releases/issues/new/choose) with your operating system, game version and reproduction steps. Reports are public; do not include credentials or personal information.
